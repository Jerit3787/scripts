What the Wizard Does

⚡

Automated Bootstrap

Clones Jerit3787/IDPS-WebServer (branch fyp2-real-detection), installs Git LFS and Python/venv, verifies the DistilBERT weights, and lets the app initialize the submodules it needs.

🎯

Current Install Modes

Production Docker Compose stack (the default) protects Juice Shop in the stack or an existing upstream. A systemd install can also use the host/development targets: VulnBank, MediVault, DVNA and CI/CD Goat.

🛡️

Multi-Tier Detection

Inline Reverse Proxy (:8081) inspects traffic via Rule Engine, DistilBERT Transformer, Behavioral Profiles, and Threat Intelligence reputation.

🌐

Cloudflare Tunnel & HTTPS

Container installs use a Zero Trust tunnel token or a Cloudflare Login named tunnel with local credentials. Host installs also support Quick Tunnels (*.trycloudflare.com) or a named tunnel. HTTPS is available through Caddy when no tunnel is used.

📊

Live SOC Dashboard

Real-time incident management, MITRE ATT&CK heatmap, request inspector, and automated IP mitigation accessible at http://localhost:8000.

🔄

Updates & Backups

Container installs get the caidps-hostd updater and a nightly backup timer. systemd installs get the caidps service and the same 03:17 backup timer.
