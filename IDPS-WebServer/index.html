CAIDPS

Context-Aware Intrusion Detection & Prevention System

Install CAIDPS with one command. The setup wizard picks a run mode, the app to protect and an optional Cloudflare Tunnel, then starts the live SOC dashboard with ML detection and behavioral profiling.

Read the docs View source

Install

Choose how this server should be set up. Run the same command again to update.

$curl -fsSL https://scripts.danplace.tech/IDPS-WebServer/setup.sh | bash

Installs or updates CAIDPS, then runs the setup wizard in your terminal.

$curl -fsSL https://scripts.danplace.tech/IDPS-WebServer/setup.sh | CAIDPS_NON_INTERACTIVE=1 bash

Production install of the Docker Compose stack with no prompts. This is the recommended setup for servers.

$curl -fsSL https://scripts.danplace.tech/IDPS-WebServer/install-image.sh | \
  CAIDPS_GHCR_TOKEN='<classic PAT with read:packages>' \
  CAIDPS_GHCR_USER=Jerit3787 \
  bash -s -- --non-interactive --profile production --run containers

For a production server that shouldn't keep a git checkout, LFS weights, submodules or a backend venv. It pulls the released app image and its host bundle. Replace the token placeholder before running.

This deletes local CAIDPS data

The reset removes the database, volumes and local data, and asks you to type reset first. Back up with scripts/backup.sh create before you run it.

$curl -fsSL https://scripts.danplace.tech/IDPS-WebServer/reset.sh | bash

What the wizard sets up

Everything below is configured by the installer. Nothing needs to be prepared by hand.

Bootstrap

Clones Jerit3787/IDPS-WebServer on fyp2-real-detection, installs Git LFS and Python with venv, verifies the DistilBERT weights, and lets the app initialize the submodules it needs.

Install modes

The default Docker Compose stack protects Juice Shop in the stack or an existing upstream. A systemd install can also target VulnBank, MediVault, DVNA and CI/CD Goat.

Multi-tier detection

The inline reverse proxy on :8081 inspects traffic with the rule engine, a DistilBERT transformer, behavioral profiles and threat-intelligence reputation.

Cloudflare Tunnel and HTTPS

Container installs use a Zero Trust tunnel token or a Cloudflare Login named tunnel. Host installs can also use Quick Tunnels (*.trycloudflare.com). Caddy serves HTTPS when there's no tunnel.

Live SOC dashboard

Incident management, a MITRE ATT&CK heatmap, a request inspector and automated IP mitigation at http://localhost:8000.

Updates and backups

Container installs get the caidps-hostd updater and a nightly backup timer. systemd installs get the caidps service and the same 03:17 backup timer.

Tunnel name already taken?

If a Cloudflare Login name already belongs to a dashboard-managed tunnel, the wizard asks for another name. To reuse that tunnel, choose the token option instead.
