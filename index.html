CAIDPS Featured Security

Context-Aware Intrusion Detection & Prevention System

A self-hosted SOC dashboard and inline reverse proxy that detects and blocks web attacks, using a rule engine, DistilBERT detection and behavioral profiling, deployed as a Docker Compose stack.

  • Docker Compose
  • systemd
  • PostgreSQL
  • Cloudflare
  • Python
$curl -fsSL https://scripts.danplace.tech/IDPS-WebServer/setup.sh | bash

Installs or updates CAIDPS, then walks you through the setup wizard. The app repository is private, so a fresh server needs GitHub access.

$curl -fsSL https://scripts.danplace.tech/IDPS-WebServer/setup.sh | CAIDPS_NON_INTERACTIVE=1 bash

Production install with the Docker Compose stack and no prompts. For an install without a git checkout, use the image-only command.

$curl -fsSL https://scripts.danplace.tech/IDPS-WebServer/reset.sh | bash

Deletes local CAIDPS data, database and volumes after you type reset. Back up first with scripts/backup.sh create, and see what it removes.

How the catalog works

  • One folder per project

    Scripts, README and an optional detail page live under <project>/. Nothing is aliased at the root.

  • One copy of each script

    Commands point at the file in the project folder, so there's no second copy to drift out of date.

  • Readable before you run

    Every script is plain bash, linted with shellcheck before it ships. Click a file name to read it here.
