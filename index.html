How the collection works

Small rules keep the catalog predictable, reviewable and easy to extend.

01

One folder per project

Every project lives under <project>/ with its own scripts, README and optional detail page. There are no root aliases.

02

One copy of each script

The catalog links to the source file in the project folder. There is no second copy that can drift out of date.

03

Read before you run

Installers are plain bash. Open the script, check what it changes, then pipe it to bash.

~/scripts $ mkdir next-project
