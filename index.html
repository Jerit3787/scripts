Automated Git & Submodules

Clones Jerit3787/IDPS-WebServer (branch fyp2-real-detection), updates submodules, and verifies Git LFS model weights automatically.

🎯

Target Selection

Choose your protected target: OWASP Juice Shop (:3000), VulnBank (:3100), MediVault (:3200), DVNA (:9090), CI/CD Goat (:3000), or bring your own upstream.

Multi-Tier Detection

Inline Reverse Proxy (:8081) inspects traffic via Rule Engine, DistilBERT Transformer, Behavioral Profiles, and Threat Intelligence reputation.

🌐

Cloudflare Tunnel Integration

One-click Quick Tunnel creates an ephemeral public HTTPS link (*.trycloudflare.com) or connects to your custom domain via Zero Trust token.

📊

Live SOC Dashboard

Real-time incident management, MITRE ATT&CK heatmap, request inspector, and automated IP mitigation accessible at http://localhost:8000.

🔄

Self-Healing Services

Built-in process keeper restarts backend and proxy services automatically if interrupted, with unified SIGINT/SIGTERM graceful shutdown.
